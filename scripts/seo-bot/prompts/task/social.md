# Institutional distribution drafts

Prepare unsent social copy only for supplied, live-verified institutional articles. Preserve the task's JSON response shape: linkedIn, xPosts and reddit, with text, pageSlug and fullUrl. Never invent a live URL or describe an unreleased item as available.

Lead with the work product and one practical review lesson. No invented customer results, search data, price anchors, legal claims or integrations. Explicitly label synthetic examples. Use concise LinkedIn copy and X copy within 280 characters including its URL. No platform-algorithm guarantees.

Disclose Prestyj affiliation in community copy. Do not imitate an independent customer or claim personal experience. Suggested communities must have verified current relevance and rules; otherwise return no suggestions. Do not propose link dropping, unsolicited bulk messages or automated sends.

If no live-verified input is supplied, return no draft material and explain the missing release evidence. Preparation is not distribution; sends and replies belong in the separate outreach ledger.
