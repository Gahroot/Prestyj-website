# Institutional research brief

Return JSON using the existing fields date, trendingAngles, gscOpportunities, competitorMoves and notes. Empty arrays are correct when evidence is unavailable. Never invent observations to satisfy a count.

Focus on reviewed deal, fund, investor, portfolio and commercial origination workflows. Proposed editorial hypotheses must be labeled hypotheses, not trends. Reserve all slugs in the institutional ledger and public registry. Only blog-post suggestions are eligible; geo, niche, comparison and automatic title rewrites remain inactive.

GSC opportunities require actual dated authenticated GSC observations with query/page scope and reporting window. Without that data return an empty gscOpportunities array and say that GSC evidence is unavailable. Bing citation exports are not GSC. Never simulate rankings, clicks, impressions or citation results.

Competitor observations require a verified primary URL, observation date and exact supported statement. Otherwise return an empty competitorMoves array. Do not infer customer results or pricing from a generic homepage. Research output is untrusted evidence for human review, not authorization to change a backlog or publish.
